# Shipd delivery checklist

Use for the selected stage. Mark PASS only with current evidence; otherwise FAIL, NOT_RUN, UNPROVEN, STALE or individually justified N/A. A reduced Scope receipt cannot satisfy full-package obligations.

## Before building
- [ ] Exact repository/commit, live contract and intended stage recorded.
- [ ] Validated denylist and public originality/implementation checks retained.
- [ ] User authorization and task-specific usage policy recorded.
- [ ] Required host, filesystem, Docker and thermal preflight passed.
- [ ] Feasibility table resolves native types, state, errors and integration boundaries.
- [ ] Independent requirement map covers input families, semantic roles and interactions.

## Before freezing Scope
- [ ] Full natural reference complete; every affected consumer compiles.
- [ ] Executable hardness witnesses reject plausible shortcuts.
- [ ] Description and solution frozen; reduced tests representative.
- [ ] Full-suite deferred obligations explicit.
- [ ] Scope local counterparts pass on exact bytes; denylist repeated.
- [ ] Specific paid Scope authorization present before launching it.

## Before full-package upload
- [ ] All requirements have grounded public witnesses; no hidden requirements.
- [ ] Complete independent discovery reconciles every partition and exclusion.
- [ ] Base checks pass on baseline; feature cases execute and fail behaviorally.
- [ ] Complete four-state matrix passes its intended outcomes.
- [ ] Native start/terminal events, exits, raw logs and JUnit reconcile.
- [ ] Existing, fresh compatibility, fresh feature and combined coverage are separated.
- [ ] Unmapped/non-executable lines, branch limitations and warnings retained.
- [ ] Targeted semantic mutants are rebuilt, witnessed, restored and classified.
- [ ] Required integrations exercise real producer/consumer and state transitions.
- [ ] Exact Docker image builds and executes offline under the current live contract.
- [ ] Dependencies and caches are reusable without stale pre-patch binaries.
- [ ] Runtime and cache/quota/thermal conditions recorded.
- [ ] Applicable Forge adversarial reviews completed; findings resolved.
- [ ] Every current live check has a local mapping; private limits explicit.
- [ ] Local evidence gate passes on exact upload inputs.
- [ ] Explicit path allowlist excludes profiles, build outputs and unrelated files.
- [ ] Artifact and runner hashes verified after transfer.
- [ ] Stale downstream gates named; specific paid gate authorized before spending.

## Before final review or acceptance claims
- [ ] Real authorized rollout cohort preserved and audited.
- [ ] False positives reproduced and fairly discriminated.
- [ ] Final local gate references current real hosted receipts.
- [ ] Auto Review approval and manager acceptance distinguished.
- [ ] Approved artifact bytes frozen with provenance; no silent drift.

## Handoff
- [ ] State, hashes, completed and unproven gates, next action and evidence paths saved.
- [ ] Original failures and repairs remain separate.
- [ ] Any task-only settings override restored at its authorized end.
- [ ] Paused work and unresolved host controls explicitly recorded.

No checklist tick, fixture test or local rubric review guarantees private Shipd success.
